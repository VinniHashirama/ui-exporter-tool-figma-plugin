O que será criado

Uma página UI Kit com os componentes canônicos, os estilos de cor e de texto, e um frame de exemplo já nomeado corretamente. Componentes que já existirem na página não são tocados.

Precisa de um componente só? Use o Criar ao lado dele — os estilos são garantidos do mesmo jeito, e nada do que já existe é mexido.

Os nomes são os mesmos que o importador da Unity procura, então usar instâncias destes componentes é o que faz a tela chegar montada do outro lado, com o comportamento dos prefabs do jogo.
