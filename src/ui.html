Componente próprio

Para o que não está no kit. Nasce com as layers de slot já nomeadas, que é o que o importador procura para saber onde escrever conteúdo.

Componentes do kit

Um Criar por componente do catálogo. Os estilos de cor e de texto são garantidos desde o primeiro, e nada do que já existe na página é mexido.

Os nomes são os mesmos que o importador da Unity procura, então usar instâncias destes componentes é o que faz a tela chegar montada do outro lado, com o comportamento dos prefabs do jogo.

Avançado: criar kit completo

Uma página UI Kit com os componentes canônicos, os estilos de cor e de texto, e um frame de exemplo já nomeado corretamente. Componentes que já existirem na página não são tocados. Raramente necessário — o normal é criar um componente de cada vez, ali em cima.
